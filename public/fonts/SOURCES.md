# Workshop typefaces

Locally hosted DM Sans (Colophon) and Lora (Cyreal), distributed under the
SIL Open Font License 1.1. The original license files are included here.
No font requests go to a third-party service at runtime.

Source files from the Google Fonts repository, retrieved October 6, 2026:

- https://github.com/google/fonts/tree/main/ofl/dmsans
- https://github.com/google/fonts/tree/main/ofl/lora

Original variable TTF files were converted to WOFF containers with FontTools.
All glyphs and variation axes were retained; no glyph designs were changed.
