        A WINDOW, NOT A CAMERA

        What are we actually seeing?

        Clawd reacts to public GitHub activity, not keystrokes. A recent push or pull request means building signals; a new branch or issue means planning signals; a published release gets a celebration.

        Running or queued GitHub Actions from this builder in the latest active repo put on the safety goggles. A workflow might be a build, a test, or another check.

        No recent signals means a quiet workshop. It doesn't prove Clawd stopped coding. Private work and unsaved code are invisible.

        The pulse is a playful recency score, not a productivity rating: weighted events decay with a 30-minute half-life. The chart covers the last hour of fetched events.

        The page checks every five minutes while visible. GitHub's public event feed can arrive 30 seconds to six hours late. On a fetch failure, we show an unknown state and label saved data.

        The public page fetches 100 public events and checks one repo’s latest 20 workflow runs. An admin-only 24-hour replay can load up to 300 feed events and merge locally saved events from the last day. It groups nearby updates to the same repo into chapters, compresses quiet gaps, and gives every chapter at least seven seconds. Busy days may run longer than the selected duration.

        Admin replay freezes its day while you watch. Historical checks are not invented from current workflows. A partial-day label appears if the public feed reaches its limit or a history page fails.

        Objects on the bench are illustrations chosen from the repo name, description, topics, or a configured mapping. They are recognizable metaphors for the project, not screenshots of the actual software. Unclear project types get a labeled blueprint.

        Workshop radio is original lo-fi synthesis that starts only after you press play. Market reactions use public Base RPC and DEX Screener data; demo mode never claims live price or chain activity.
